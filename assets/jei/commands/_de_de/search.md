# search

**Verwendung:** `/jei search [text]`

Setzt die Suche der Gegenstandsliste wie das Tippen in ihr Feld; ohne Text leert er sie. `@mod`, `#Tooltip`, `$Tag` und `-Wort` funktionieren wie im Feld.
